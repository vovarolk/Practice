## Абстрактный класс: EnvironmentEffect

### Назначение
Абстрактный класс для AR‑эффектов окружения, вызванных реальными условиями погоды или локации. Эффекты могут быть как положительными (благословения), так и отрицательными (штрафы), влияя на боевые характеристики, здоровье и видимость. Это система взаимодействия с окружающей средой.

### Директория и файл
```
EnvironmentEffect.kt
```

### Переменные класса

| Переменная   | Тип       | Область видимости  | Описание                          | Начальное значение   |
|--------------|-----------|--------------------|-----------------------------------|----------------------|
| `name`       | `String`  | `abstract var`     | Название эффекта                  | ""                   |
| `isActive`   | `Boolean` | `abstract var`     | Активен ли эффект в данный момент | false                |
| `duration`   | `Int`     | `abstract var`     | Длительность эффекта в секундах   | 0                    |
| `intensity`  | `Int`     | `abstract var`     | Интенсивность эффекта (0–100%)    | 50                   |

### Определение переменных

Все переменные объявляются как `abstract var` в абстрактном классе, что позволяет каждому наследнику иметь свои собственные значения.

### Абстрактные методы

#### Метод 1: activate()
```kotlin
abstract fun activate(): Unit
```
**Описание:** Активировать эффект и начать его действие. Вызывается при возникновении условий окружения.

**Параметры:** Нет

**Возвращаемое значение:** `Unit` (ничего)

**Требования:**
- Установить `isActive = true`
- Вывести сообщение об активации эффекта
- Каждый эффект имеет уникальное сообщение

---

#### Метод 2: deactivate()
```kotlin
abstract fun deactivate(): Unit
```
**Описание:** Деактивировать эффект и прекратить его действие. Вызывается при истечении длительности или изменении условий.

**Параметры:** Нет

**Возвращаемое значение:** `Unit` (ничего)

**Требования:**
- Установить `isActive = false`
- Вывести сообщение об деактивации
- Очистить эффекты (если нужно)

---

#### Метод 3: updateEffect()
```kotlin
abstract fun updateEffect(): Unit
```
**Описание:** Обновить состояние эффекта каждый ход/кадр. Уменьшает длительность и обновляет параметры.

**Параметры:** Нет

**Возвращаемое значение:** `Unit` (ничего)

**Требования:**
- Проверить `isActive` и `duration`
- Уменьшить `duration` на 1 каждое обновление
- При `duration <= 0` вызвать `deactivate()`
- Вывести сообщение о текущем состоянии (опционально)

---

#### Метод 4: render()
```kotlin
abstract fun render(): Unit
```
**Описание:** Отрисовать визуальное представление эффекта в AR. Описывает, как эффект выглядит на экране.

**Параметры:** Нет

**Возвращаемое значение:** `Unit` (ничего)

**Требования:**
- Вывести сообщение о визуальном представлении
- Использовать эмодзи и описание для наглядности
- Каждый эффект имеет уникальную визуализацию

---

#### Метод 5: getDurationFun(): Int
```kotlin
abstract fun getDurationFun(): Int
```
**Описание:** Вернуть оставшуюся длительность эффекта в секундах.

**Параметры:** Нет

**Возвращаемое значение:** `Int` — количество секунд до конца эффекта

**Требования:**
- Возвращать текущее значение `duration`
- Используется для отображения таймера эффекта

## Наследник 1: SunBless (Благословение Солнца)

### Назначение
Положительный эффект окружения, активируется на солнечных локациях (в ясный день). Восстанавливает здоровье персонажу со временем. Это пассивное благо природы, которое помогает игроку без его инициативы.

### Директория и файл
```
SunBless.kt
```

### Родительский класс
```kotlin
class SunBless : EnvironmentEffect()
```

### Специальные переменные класса

| Переменная      | Тип   | Область видимости   | Описание                        | Начальное значение   |
|-----------------|-------|---------------------|---------------------------------|----------------------|
| `healPerSecond` | `Int` | `var`               | HP восстанавливаемых за секунду | 5                    |

### Инициализация в init блоке
```
name = "Благословение Солнца"
duration = 600 (10 минут)
healPerSecond = 5
isActive = false
intensity = 100 (максимум)
```

### Реализация методов

#### Метод: activate()
**Логика:**
1. Установить `isActive = true`
2. Вывести сообщение об активации

**Пример вывода:**
```
☀️ Солнце светит ярко! HP восстанавливается!
```

**Назначение:** Уведомить игрока, что начался благоприятный эффект солнца

---

#### Метод: deactivate()
**Логика:**
1. Установить `isActive = false`
2. Вывести сообщение об окончании

**Пример вывода:**
```
Солнце скрылось за облаками
```

---

#### Метод: updateEffect()
**Логика:**
1. Если `isActive` и `duration > 0`:
   - Вывести: `"Восстановление HP: +[healPerSecond]"`
   - Уменьшить `duration` на 1
2. Если `duration <= 0`, вызвать `deactivate()`

**Пример вывода за один ход:**
```
Восстановление HP: +5
```

**Поведение:**
- Каждый вызов `updateEffect()` — это один ход в игре
- Эффект продолжается 600 ходов (10 минут в игровом времени)
- Каждый ход восстанавливается 5 HP

---

#### Метод: render()
**Логика:**
1. Вывести описание визуального эффекта

**Пример вывода:**
```
Экран освещён золотистым светом
```

**Описание визуализации:**
- Золотистый фильтр на экране
- Ярче, чем обычно
- Создаёт ощущение здоровья и благополучия

---

#### Метод: getDurationFun(): Int
**Логика:**
1. Вернуть текущее значение `duration`

**Примеры:**
- В начале: 600
- В середине: 300
- В конце: 1

## Наследник 3: Fog (Туман)

### Назначение
Нейтральный эффект окружения, ограничивающий видимость. Туман постепенно рассеивается с течением времени. Усложняет ориентацию на карте и дальнобойные атаки, создавая атмосферу тайны.

### Директория и файл
```
Fog.kt
```

### Родительский класс
```kotlin
class Fog : EnvironmentEffect()
```

### Специальные переменные класса

| Переменная   | Тип   | Область видимости | Описание                   | Начальное значение |
|--------------|-------|-------------------|----------------------------|--------------------|
| `visibility` | `Int` | `var`             | Процент видимости (0–100%) | 30 при активации   |

### Инициализация в init блоке
```
name = "Туман"
duration = 300 (5 минут)
visibility = 30 (при активации)
isActive = false
intensity = 50 (средний эффект)
```

### Реализация методов

#### Метод: activate()
**Логика:**
1. Установить `isActive = true`
2. Установить `visibility = 30` (начальная видимость)
3. Вывести сообщение об появлении тумана

**Пример вывода:**
```
🌫️ На карте появился плотный туман!
```

**Назначение:** Включить туман и установить низкую видимость

---

#### Метод: deactivate()
**Логика:**
1. Установить `isActive = false`
2. Вывести сообщение об рассеивании

**Пример вывода:**
```
Туман рассеялся
```

---

#### Метод: updateEffect()
**Логика:**
1. Если `isActive`:
   - Увеличить `visibility` на 5 (туман постепенно рассеивается)
   - Уменьшить `duration` на 1
   - Если `visibility >= 100`, вызвать `deactivate()`
2. Если `duration <= 0`, вызвать `deactivate()`

**Пример вывода за один ход:**
```
Видимость улучшается: 35%
```

**Поведение:**
- Туман не исчезает мгновенно
- С каждым ходом видимость улучшается на 5%
- После 14 ходов видимость станет 100% и туман рассеется
- Или туман может рассеяться по времени (duration = 0)

**Прогрессия видимости:**
- Ход 1: 30% → 35%
- Ход 2: 35% → 40%
- ...
- Ход 14: 95% → 100% (туман рассеялся)

---

#### Метод: render()
**Логика:**
1. Вывести описание визуального эффекта с текущей видимостью

**Пример вывода:**
```
На экране видна серая дымка, видимость: 35%
```

**Описание визуализации:**
- Серый туман покрывает экран
- Чем ниже видимость, тем плотнее туман
- Размытые очертания объектов
- Эффект прозрачности в зависимости от видимости

**Примеры в разные моменты:**
- Начало: "На экране видна серая дымка, видимость: 30%"
- Середина: "На экране видна серая дымка, видимость: 60%"
- Конец: "На экране видна серая дымка, видимость: 95%"

---

#### Метод: getDurationFun(): Int
**Логика:**
1. Вернуть текущее значение `duration`

**Примеры:**
- В начале: 300
- В середине: 150
- В конце: 1

## Требования к реализации

### Код на Kotlin
- Все классы должны быть написаны на **Kotlin**
- Использовать **`abstract`** для абстрактного класса
- Использовать **`:` для наследования**
- Использовать **`init`** блок для инициализации переменных

### Переменные
- В абстрактном классе использовать `abstract var`
- В наследниках использовать `override var` или `var`
- Использовать `val` для неизменяемых данных (если возможно)

### Методы
- Все абстрактные методы ДОЛЖНЫ быть переопределены в наследниках
- Использовать `override` для переопределения
- Каждый метод должен иметь чёткую логику
- Метод `updateEffect()` вызывается каждый ход/кадр

### Вывод
- Использовать `println()` для вывода сообщений
- Использовать эмодзи для визуального улучшения: ☀️, 🌧️, 🌫️
- Выводить информативные сообщения с параметрами

### Логика времени
- `duration` уменьшается на 1 при каждом вызове `updateEffect()`
- Когда `duration` становится <= 0, эффект автоматически деактивируется
- Каждый ход = 1 секунда в игровом времени

## Пример использования

```kotlin
// Создание эффекта солнца
val sunBless = SunBless()
sunBless.activate()  // Активируется

// Обновление каждый ход
for (i in 1..5) {
    sunBless.updateEffect()  // Выводит восстановление HP
    println("Длительность: ${sunBless.getDurationFun()}")  // 599, 598, 597...
}

sunBless.render()  // Показывает золотистый эффект

// Создание дождя
val rain = RainDebuff()
rain.activate()  // Начинается дождь

rain.render()  // Показывает капли дождя
for (i in 1..3) {
    rain.updateEffect()  // Выводит "Идёт дождь..."
}

// Создание тумана
val fog = Fog()
fog.activate()  // Активируется туман, visibility = 30%

for (i in 1..10) {
    fog.updateEffect()  // Видимость постепенно растёт
    println("Видимость: ${fog.visibility}%")
}

fog.render()  // Показывает серую дымку с текущей видимостью
```
