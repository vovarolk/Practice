## Абстрактный класс: Spell

### Назначение
Абстрактный класс для магических заклинаний с поддержкой каста, улучшений и эффектов. Заклинания расходуют ману, имеют перезарядку (cooldown) и могут быть улучшены. Это основа магической системы игры.

### Директория и файл
```
Spell.kt
```

### Переменные класса

| Переменная    | Тип      | Область видимости | Описание                             | Начальное значение |
|---------------|----------|-------------------|--------------------------------------|--------------------|
| `name`        | `String` | `abstract var`    | Название заклинания                  | ""                 |
| `manaCost`    | `Int`    | `abstract var`    | Стоимость маны для каста             | 20                 |
| `level`       | `Int`    | `abstract var`    | Уровень заклинания (определяет силу) | 1                  |
| `cooldown`    | `Int`    | `abstract var`    | Текущее значение перезарядки в ходах | 0                  |
| `maxCooldown` | `Int`    | `abstract var`    | Максимальное значение перезарядки    | 5                  |

### Определение переменных

Все переменные объявляются как `abstract var` в абстрактном классе, что позволяет каждому наследнику иметь свои собственные значения.

### Абстрактные методы

#### Метод 1: cast(): Int
```kotlin
abstract fun cast(): Int
```
**Описание:** Активировать заклинание и вернуть урон/эффект. Вызывает визуальный эффект и устанавливает перезарядку.

**Параметры:** Нет

**Возвращаемое значение:** `Int` — урон, защита или другой числовой эффект

**Требования:**
- Вывести сообщение о касте
- Вызвать `showEffect()` для визуализации
- Установить `cooldown = maxCooldown`
- Вернуть числовое значение эффекта

**Примеры значений:**
- Fireball: возвращает урон (40, 60 и т.д.)
- Shield: возвращает поглощение урона (40, 60 и т.д.)
- Blink: возвращает 0 (утилитарное заклинание)

---

#### Метод 2: getManaCost(): Int
```kotlin
abstract fun getManaCost(): Int
```
**Описание:** Вернуть текущую стоимость маны. Может меняться с уровнем заклинания.

**Параметры:** Нет

**Возвращаемое значение:** `Int` — стоимость маны

**Требования:**
- Вычислить стоимость на основе текущего уровня
- Каждое заклинание имеет свою формулу
- Результат должен быть положительным числом

**Примеры:**
- Fireball: `manaCost + (level - 1) * 5` → уровень 1 = 30, уровень 5 = 50
- Shield: `manaCost` → всегда 20
- Blink: `manaCost - (level - 1)` → уровень 1 = 15, уровень 4 = 12

---

#### Метод 3: upgrade()
```kotlin
abstract fun upgrade(): Unit
```
**Описание:** Увеличить уровень заклинания и его параметры (урон, защита, дальность и т.д.).

**Параметры:** Нет

**Возвращаемое значение:** `Unit` (ничего)

**Требования:**
- Увеличить `level` на 1
- Улучшить основные параметры заклинания (урон, защита, дальность и т.д.)
- Вывести сообщение об улучшении
- Каждое заклинание улучшает свои параметры по-своему

**Примеры:**
- Fireball: уровень +1, baseDamage +15
- Shield: уровень +1, absorb +20, duration +2
- Blink: уровень +1, range +2

---

#### Метод 4: cancel()
```kotlin
abstract fun cancel(): Unit
```
**Описание:** Отменить заклинание — обнулить cooldown, прервать каст или рассеять эффект.

**Параметры:** Нет

**Возвращаемое значение:** `Unit` (ничего)

**Требования:**
- Обнулить `cooldown` (или другую логику прерывания)
- Вывести сообщение об отмене
- Каждое заклинание имеет свой способ отмены

---

#### Метод 5: showEffect()
```kotlin
abstract fun showEffect(): Unit
```
**Описание:** Визуальный эффект заклинания в AR. Выводит описание визуального представления.

**Параметры:** Нет

**Возвращаемое значение:** `Unit` (ничего)

**Требования:**
- Вывести яркое сообщение с описанием эффекта
- Использовать эмодзи для наглядности
- Каждое заклинание имеет уникальный эффект

## Наследник 1: Fireball

### Назначение
Наступательное заклинание, наносящее урон огнём. Fireball — основное заклинание для магов с высоким уроном. Это агрессивное заклинание для борьбы с врагами.

### Директория и файл
```
Fireball.kt
```

### Родительский класс
```kotlin
class Fireball : Spell()
```

### Специальные переменные класса

| Переменная   | Тип   | Область видимости | Описание                | Начальное значение |
|--------------|-------|-------------------|-------------------------|--------------------| 
| `baseDamage` | `Int` | `var`             | Базовый урон заклинания | 30                 |

### Инициализация в init блоке
```
name = "Огненный шар"
manaCost = 30
baseDamage = 30
level = 1
cooldown = 0
maxCooldown = 5
```

### Реализация методов

#### Метод: cast(): Int
**Формула урона:**
```
damage = baseDamage + (level * 10)
```

**Примеры:**
- Уровень 1: 30 + (1 × 10) = 40
- Уровень 3: 30 + (3 × 10) = 60
- Уровень 5: 30 + (5 × 10) = 80

**Логика:**
1. Вычислить урон по формуле
2. Вывести сообщение: `"Маг запускает Огненный шар, урон: [урон]"`
3. Вызвать `showEffect()`
4. Установить `cooldown = maxCooldown` (5)
5. Вернуть вычисленный урон

**Пример вывода:**
```
Маг запускает Огненный шар, урон: 60
```

---

#### Метод: getManaCost(): Int
**Формула:**
```
manaCost + (level - 1) * 5
```

**Примеры:**
- Уровень 1: 30 + (1 - 1) × 5 = 30
- Уровень 3: 30 + (3 - 1) × 5 = 40
- Уровень 5: 30 + (5 - 1) × 5 = 50

**Логика:**
- По мере повышения уровня стоимость маны увеличивается
- Это делает высокоуровневые заклинания более затратными

---

#### Метод: upgrade()
**Логика:**
1. Увеличить `level` на 1
2. Увеличить `baseDamage` на 15
3. Вывести сообщение об улучшении

**Пример вывода:**
```
Огненный шар улучшен до уровня 2, урон: 45
```

**Прогрессия урона при улучшениях:**
- Уровень 1: базовый урон 30
- Уровень 2: базовый урон 45
- Уровень 3: базовый урон 60
- Уровень 4: базовый урон 75
- Уровень 5: базовый урон 90

---

#### Метод: cancel()
**Логика:**
1. Установить `cooldown = 0`
2. Вывести сообщение об отмене

**Пример вывода:**
```
Огненный шар отменена
```

---

#### Метод: showEffect()
**Логика:**
1. Вывести сообщение с эмодзи о визуальном эффекте

**Пример вывода:**
```
💥 Огненный взрыв на AR‑экране!
```

## Требования к реализации

### Код на Kotlin
- Все классы должны быть написаны на **Kotlin**
- Использовать **`abstract`** для абстрактного класса
- Использовать **`:` для наследования**
- Использовать **`init`** блок для инициализации переменных

### Переменные
- В абстрактном классе использовать `abstract var`
- В наследниках использовать `override var` или `var`
- Использовать `val` для неизменяемых данных (если возможно)

### Методы
- Все абстрактные методы ДОЛЖНЫ быть переопределены в наследниках
- Использовать `override` для переопределения
- Каждый метод должен иметь чёткую логику

### Вывод
- Использовать `println()` для вывода сообщений
- Использовать эмодзи для визуального улучшения: 💥, 🛡️, ✨
- Выводить информативные сообщения с параметрами

### Вычисления
- Урон/защита должны быть целыми числами (`Int`)
- Уровень начинается с 1 и увеличивается при `upgrade()`
- Cooldown должен устанавливаться при касте

---

## Пример использования

```kotlin
// Создание Fireball
val fireball = Fireball()
val damage = fireball.cast()  // урон = 40 (уровень 1)
println("Урон: $damage")

// Улучшение
fireball.upgrade()  // уровень 2, baseDamage = 45
val newDamage = fireball.cast()  // урон = 55 (45 + 2*10)
println("Новый урон: $newDamage")

// Проверка маны
println("Стоимость маны: ${fireball.getManaCost()}")  // 35

// Создание Shield
val shield = Shield()
val protection = shield.cast()  // protection = 40
println("Защита: $protection")

// Создание Blink
val blink = Blink()
blink.cast()  // дистанция = 5
blink.upgrade()  // уровень 2, range = 7
println("Дистанция: ${blink.range}")
```
