# Техническое задание: Entity System (Базовые игровые объекты)


## Абстрактный класс: Entity

### Назначение
Абстрактный базовый класс для всех существ в мире AR‑RPG. Определяет базовую функциональность для любого игрового персонажа, монстра или NPC. Это фундамент системы взаимодействия объектов в игровом пространстве.

### файл
Entity.kt


### Переменные класса

| Переменная | Тип      | Область видимости | Описание                       | Начальное значение |
|------------|----------|-------------------|--------------------------------|--------------------|
|  `x`       | `Float`  | `var`             | Координата X в AR‑пространстве | 0f                 |
| `y`        | `Float`  | `var`             | Координата Y в AR‑пространстве | 0f                 |
| `hp`       | `Int`    | `var`             | Текущее здоровье               | 100                |
| `maxHp`    | `Int`    | `var`             | Максимальное здоровье          | 100                |
| `name`     | `String` | `var`             | Имя существа                   | ""                 |

### Абстрактные методы

#### Метод 1: attack()
```kotlin
abstract fun attack(): Int
```
**Описание:** Вычисляет урон при атаке и возвращает значение урона.

**Параметры:** Нет

**Возвращаемое значение:** `Int` — урон в единицах

**Требования:**
- Каждый класс-наследник вычисляет урон по-своему
- Урон должен быть положительным числом
- Должна быть база для вычисления (например, базовая атака + бонусы)

---

#### Метод 2: takeDamage(damage: Int)
```kotlin
abstract fun takeDamage(damage: Int): Unit
```
**Описание:** Получить урон. Если HP становится <= 0, вызвать `die()`.

**Параметры:**
- `damage: Int` — количество урона для получения

**Возвращаемое значение:** `Unit` (ничего)

**Требования:**
- HP не может быть отрицательным
- При HP <= 0 автоматически вызвать `die()`
- Каждый класс может иметь свою логику обработки урона

---

#### Метод 3: move(newX: Float, newY: Float)
```kotlin
abstract fun move(newX: Float, newY: Float): Unit
```
**Описание:** Переместить объект на новые координаты в AR‑пространстве.

**Параметры:**
- `newX: Float` — новая координата X
- `newY: Float` — новая координата Y

**Возвращаемое значение:** `Unit` (ничего)

**Требования:**
- Обновить переменные `x` и `y`
- Каждый класс может добавить свою логику (например, монстр может двигаться по-другому)

---

#### Метод 4: interact()
```kotlin
abstract fun interact(): Unit
```
**Описание:** Взаимодействие с окружением или другими объектами.

**Параметры:** Нет

**Возвращаемое значение:** `Unit` (ничего)

**Требования:**
- Логика взаимодействия зависит от типа существа
- Игрок может взаимодействовать с предметами
- Монстр нападает при взаимодействии
- Торговец открывает окно торговли

---

#### Метод 5: render()
```kotlin
abstract fun render(): Unit
```
**Описание:** Отрисовка существа в AR‑пространстве на экран.

**Параметры:** Нет

**Возвращаемое значение:** `Unit` (ничего)

**Требования:**
- Визуально отобразить существо в AR
- Каждый класс имеет свой способ отрисовки
- Должна учитывать координаты (x, y)

---

#### Метод 6: die()
```kotlin
abstract fun die(): Unit
```
**Описание:** Обработка жизненного пути существа. Вызывается при HP <= 0.

**Параметры:** Нет

**Возвращаемое значение:** `Unit` (ничего)

**Требования:**
- Установить HP = 0
- Каждый класс может иметь свой способ реализации метода
- Не удалять объект из памяти (это сделает управление памятью позже)

## Наследник 1: Player

### Назначение
Класс для управления аватаром игрока. Представляет основного персонажа, которым управляет игрок через интерфейс приложения. Player — это главный герой истории.

### Директория и файл
```
Player.kt
```

### Родительский класс
```kotlin
class Player : Entity()
```

### Специальные переменные класса

| Переменная   | Тип     | Область видимости | Описание               | Начальное значение |
|--------------|---------|-------------------|------------------------|--------------------|
| `level`      | `Int`   | `var`             | Уровень персонажа      | 1                  |
| `experience` | `Int`   | `var`             | Общее количество опыта | 0                  |

### Реализация методов

#### Метод: attack(): Int
**Формула урона:**
```
damage = 15 + level * 5
```

**Примеры:**
- Уровень 1: урон = 15 + 1×5 = 20
- Уровень 5: урон = 15 + 5×5 = 40
- Уровень 10: урон = 15 + 10×5 = 65

**Логика:**
1. Вычислить урон по формуле
2. Вывести сообщение: `"Игрок атакует с уроном: [урон]"`
3. Вернуть вычисленный урон

**Пример вывода:**
```
Игрок атакует с уроном: 40
```

---

#### Метод: takeDamage(damage: Int)
**Логика:**
1. Уменьшить `hp` на значение `damage`
2. Если `hp <= 0`, вызвать `die()`
3. Вывести сообщение о полученном урона

**Пример вывода:**
```
Игрок получил 25 урона. Здоровье: 75/100
```

**Внимание:** HP не должно быть ниже 0 даже перед вызовом `die()`

---

#### Метод: move(newX: Float, newY: Float)
**Логика:**
1. Обновить переменные: `x = newX`, `y = newY`
2. Вывести сообщение о перемещении

**Пример вывода:**
```
Игрок переместился на (25.5, 30.0)
```

---

#### Метод: interact()
**Логика:**
1. Вывести сообщение о взаимодействии

**Пример вывода:**
```
Игрок взаимодействует с окружением
```

---

#### Метод: render()
**Логика:**
1. Вывести сообщение о отрисовке

**Пример вывода:**
```
Отрисовка аватара игрока на AR‑экран
```

---

#### Метод: die()
**Логика:**
1. Установить `hp = 0`
2. Вывести сообщение 

**Пример вывода:**
```
Игрок повержен! Перезагрузка...
```

---

## Наследник 2: Monster

### Назначение
Класс для враждебных существ, которые атакуют игрока и других персонажей. Монстры управляются игровой логикой и AI. Они враги, которых нужно побеждать.

### Директория и файл
```
Monster.kt
```

### Родительский класс
Entity()


### Специальные переменные класса

| Переменная | Тип      | Область видимости | Описание                 | Начальное значение |
|------------|----------|-------------------|--------------------------|--------------------|
| `type`     | `String` | `var`             | Тип монстра (раса/класс) | "Goblin"           |

### Типы монстров
- "Goblin" — гоблин (слабый враг)
- "Orc" — орк (средний враг)
- "Dragon" — дракон (сильный враг)
- "Troll" — тролль (выносливый враг)

### Реализация методов

#### Метод: attack(): Int
**Формула урона:**
```
damage = 8 + (maxHp / 20)
```

**Примеры:**
- maxHp = 100: урон = 8 + (100/20) = 8 + 5 = 13
- maxHp = 200: урон = 8 + (200/20) = 8 + 10 = 18
- maxHp = 60: урон = 8 + (60/20) = 8 + 3 = 11

**Логика:**
1. Вычислить урон по формуле (урон зависит от здоровья монстра)
2. Вернуть вычисленный урон
3. Вывод необязателен (молчаливая атака)

---

#### Метод: takeDamage(damage: Int)
**Логика:**
1. Уменьшить `hp` на значение `damage`
2. Если `hp <= 0`, вызвать `die()`
3. Вывести сообщение о полученном урона

**Пример вывода:**
```
Монстр Goblin получил 15 урона. Здоровье: 85/100
```

---

#### Метод: move(newX: Float, newY: Float)
**Логика:**
1. Обновить переменные: `x = newX`, `y = newY`
2. НЕ выводить сообщение (молчаливое перемещение)

**Причина:** Монстры движутся часто, и вывод забьёт консоль

---

#### Метод: interact()
**Логика:**
1. Вывести сообщение о нападении

**Пример вывода:**
```
Монстр Goblin нападает!
```

---

#### Метод: render()
**Логика:**
1. Вывести сообщение о отрисовке с типом монстра

**Пример вывода:**
```
Монстр Goblin визуализируется в AR‑пространстве
```

---

#### Метод: die()
**Логика:**
1. Установить `hp = 0`
2. Вывести сообщение о смерти с типом монстра

**Пример вывода:**
```
Монстр Goblin побеждён!
```

## Наследник 3: Merchant

### Назначение
Класс для торговца, который не атакует и не может быть убит. Торговец имеет инвентарь с товарами и может взаимодействовать с игроком через торговлю. Торговец — это дружественный NPC.

### Директория и файл
```
Merchant.kt
```

### Родительский класс
```kotlin
class Merchant : Entity()
```

### Специальные переменные класса

| Переменная | Тип | Область видимости | Описание | Начальное значение |
|-----------|-----|------------------|---------|-------------------|
| `inventory` | `MutableList<String>` | `var` | Список товаров | `mutableListOf("Зелье", "Свиток")` |

### Реализация методов

#### Метод: attack(): Int
**Логика:**
1. Вернуть `0` (торговец не атакует)

**Обоснование:** Торговец — мирный NPC и не участвует в боях

---

#### Метод: takeDamage(damage: Int)
**Логика:**
1. Вывести сообщение о бегстве (торговец убегает при попытке его ударить)
2. НЕ уменьшать `hp` (торговец безуязвим)

**Пример вывода:**
```
Торговец убегает!
```

**Назначение:** Защита NPC торговца от случайных ударов игрока

---

#### Метод: move(newX: Float, newY: Float)
**Логика:**
1. Обновить переменные: `x = newX`, `y = newY`
2. НЕ выводить сообщение (молчаливое перемещение)

---

#### Метод: interact()
**Логика:**
1. Вывести сообщение о торговле с списком товаров

**Пример вывода:**
```
Торговец: Что ты хочешь купить? У меня есть: [Зелье, Свиток]
```

**Формат вывода:**
```
Торговец: Что ты хочешь купить? У меня есть: {список товаров через запятую}
```

---

#### Метод: render()
**Логика:**
1. Вывести сообщение о появлении торговца

**Пример вывода:**
```
Торговец появляется на экране
```

---

#### Метод: die()
**Логика:**
1. Установить `hp = 0` (для совместимости)
2. Вывести сообщение о исчезновении
3. Инвентарь остаётся доступным

**Пример вывода:**
```
Торговец исчез...
```


## Пример использования

```kotlin
// Создание игрока
val player = Player()
player.name = "Герой"
player.hp = 100
player.maxHp = 100
player.level = 5

// Атака игрока
val playerDamage = player.attack() // 15 + 5*5 = 40

// Создание монстра
val monster = Monster()
monster.name = "Враг"
monster.type = "Goblin"
monster.hp = 80
monster.maxHp = 80

// Монстр получает урон
monster.takeDamage(playerDamage) // Goblin получит 40 урона

// Монстр атакует в ответ
val monsterDamage = monster.attack() // 8 + 80/20 = 12
player.takeDamage(monsterDamage)

// Создание торговца
val merchant = Merchant()
merchant.name = "Торговец Иван"
merchant.move(15f, 25f)
merchant.interact() // Вывод товаров
```
